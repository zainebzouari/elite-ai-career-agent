## n8n Learning Resources

n8n is a powerful open-source workflow automation tool that allows you to connect different services and automate complex processes without extensive coding. The following resources are excellent starting points for beginners and intermediate users.

### Official Documentation & Courses

*   **n8n Docs - Text Courses** [1]: The official n8n documentation offers structured learning paths with text-based courses, including Level 1 (Beginner) and Level 2 (Intermediate) courses. These cover fundamental concepts and advanced workflows.
*   **n8n Docs - Learning Path** [2]: A suggested learning path that guides users through tutorials, courses, and step-by-step guides to get started with n8n.

### Video Tutorials

*   **n8n Docs - Video Courses** [3]: n8n provides two main video courses on YouTube: a Beginner course covering basics like workflows, APIs, webhooks, and nodes, and an Advanced course for more complex workflows, technical nodes, and enterprise features.
*   **Ultimate n8n Course: Beginner to Pro in 17 Hours (2026)** [4]: A comprehensive YouTube course that covers n8n from beginner to professional levels, including workflow JSON files for free.
*   **n8n Quick Start Tutorial: Build Your First Workflow [2025]** [5]: A YouTube tutorial focusing on the key fundamentals of building n8n workflows, including triggers and actions.
*   **n8n Tutorial for Beginners: How to Build AI Automations for Free** [6]: This video demonstrates how to build AI automations using n8n, highlighting its open-source and powerful capabilities.

## AI Agents Learning Resources

AI agents extend the capabilities of Large Language Models (LLMs) by enabling goal-oriented task completion, decision-making, and tool utilization. Integrating AI agents with n8n allows for sophisticated automation.

### General AI Agents Courses

*   **AI Agents for Beginners (Microsoft)** [7]: A 10-lesson course from Microsoft that covers the fundamentals of building AI agents, taking learners from concept to code. The course also has a corresponding GitHub repository with code samples [8].
*   **Mastering AI Agents: The 10 Best Free Courses, Tutorials & Learning Tools** [9]: A Medium article compiling a list of free courses and resources for mastering AI agents.
*   **AI Agent Course: Free Online Training (Salesforce)** [10]: Salesforce Trailhead offers free, interactive courses to learn about AI and build AI agents, suitable for beginners and those with some tech experience.

### n8n & AI Agents Integration

*   **Tutorial: Build an AI workflow in n8n** [11]: An introductory tutorial in the n8n documentation that guides users through building AI workflows with n8n, including how to construct a working AI-powered chat agent.
*   **AI Agent node documentation | n8n Docs** [12]: Technical documentation on how to use the AI Agent node in n8n and integrate it into workflows.
*   **LangChain concepts in n8n - n8n Docs** [13]: Explains how LangChain can be used within n8n workflows, allowing integration with other services.
*   **LangChain learning resources | n8n Docs** [14]: Provides a list of helpful external and internal resources for learning LangChain, including official documentation, code templates, and a YouTube series.
*   **How to Build AI Agents with n8n in 2025! (Full Course)** [15]: A YouTube course dedicated to building AI agents with n8n.
*   **Learn n8n to Design, Develop, and Deploy Production-Grade AI Agents** [16]: A FreeCodeCamp article that covers integrating APIs, automating processes, and orchestrating intelligent agents using n8n.
*   **How to Build AI Agents with n8n for Automation - Strapi** [17]: A guide on building AI agents with n8n using LangChain integration, covering workflow architecture and LLM configuration.

## Free n8n Template GitHub Repositories

These GitHub repositories offer a wealth of pre-built n8n workflows and templates that can be imported and customized for various automation tasks, including those involving AI.

*   **enescingoz/awesome-n8n-templates** [18]: A comprehensive collection of n8n automation templates covering a wide range of tasks and integrations, including AI-powered automations.
*   **wassupjay/n8n-free-templates** [19]: A curated set of over 200 plug-and-play n8n workflows that combine classic automation with modern AI stack components like vector databases, embeddings, and LLMs.
*   **emretasss/AI-Workflow-Hub-2000-** [20]: A collection of over 2000 free n8n AI automation workflows designed to help users leverage AI and automation, with workflows organized into categories like AI & Machine Learning, Data Processing, and Web Automation.
*   **Marvomatic/n8n-templates** [21]: A collection of free and premium n8n templates for automating tasks related to SEO, content optimization, and data analysis.
*   **AmplifyAutomation/n8n-templates** [22]: A collection of resources designed to help navigate AI automation and maximize business efficiency.
*   **Danitilahun/n8n-workflow-templates** [23]: A professionally organized collection of over 2,000 n8n workflows with a fast documentation system.
*   **zengfr/n8n-workflow-all-templates** [24]: A massive collection of over 8,200 n8n workflows, synchronized and updated regularly.
